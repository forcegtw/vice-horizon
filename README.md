# Vice Horizon

An open-world crime game that runs in the browser: steal cars, outrun the police, and run
cash-cache missions across a neon city — built with three.js and plain ES modules, no build step.

## Play

```bash
node serve.ts        # serve the game at http://localhost:8080
```

Controls: **WASD** walk / drive · **Shift** sprint · **F** enter or steal a car · **LMB** attack ·
**P** pause.

## What's in it

- Three vehicle bodies (sedan/coupe, van, truck) with extruded profiles, glass canopies, torus
  tires on spoked rims and emissive lights
- A day/night cycle with a shader sky, warm sun, moonlight, neon signage and lit facades
- Traffic that brakes for cars, police that escalates with your wanted level, pedestrians that flee
  gunfire, cash-cache and delivery missions, minimap HUD, and WebAudio sound effects
